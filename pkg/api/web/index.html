LANCEMENT T2C PHANTOM

Configurer tes navigateurs pour les sites .t2c ?

Un clic, et tous tes navigateurs (Chrome, Edge, Safari, Brave, Firefox, Zen…) ouvrent les sites .t2c en HTTPS, sans réglage manuel :

  1. la CA locale est installée — générée sur ta machine, elle ne peut signer que des noms .t2c (jamais ta banque ni un autre site) ;
  2. le proxy se règle tout seul : seuls les .t2c passent par T2C Phantom, le reste de ta navigation ne change pas ;
  3. à la fermeture de l’app, tes réglages proxy d’origine sont remis.

Sans outil d’installation disponible (certains Linux), le fichier tutodecode-ca.crt est proposé à importer à la main.
